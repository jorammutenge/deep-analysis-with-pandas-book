## About the Book

**Deep Analysis with Pandas** is a comprehensive guide to executing advanced analytical queries with the pandas library, offering clear, in-depth coverage for tackling complex data tasks.

This book brings together years of experience from the author, Joram Mutenge, a data professional focused on extracting value from complex datasets.

## How to Use This Repository

All code examples from the book are available here.

## Datasets

To get all the datasets used in this book, download the [data zip file](https://drive.google.com/file/d/1ETxGtLYz7kVgBwbk2JaXKelOvnQr-BOf/view?usp=drive_link) and unzip it. Make sure you place the data folder in the same folder that contains `book-code.ipynb`.
